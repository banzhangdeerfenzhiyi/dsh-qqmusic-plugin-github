# Security & privacy

## What this plugin touches

| Data | Where it goes |
|---|---|
| QQ Music account cookie (`uin` + `qqmusic_key`) | `~/.dsh/qqmusic/cookie.json` on this machine only, sent only to `u.y.qq.com` / `dl.stream.qqmusic.qq.com` as the normal `Cookie` header |
| Chat text needed to find a song | sent only to the QQ Music search endpoint |
| Rendered audio, downloaded songs, intermediate stems | local cache under `<rvcRoot>/songs/qqmusic/` (or `<DSH_HOME>/qqmusic-cache/`) |
| WeChat voice bubbles | local WeChatAgent hook (`127.0.0.1:30001`); it builds the message and WeChat sends it |
| QQ voice records | local NapCat OneBot WebSocket (`127.0.0.1:3001`) |
| Logs | `~/.dsh/qqmusic/qqmusic.log`, no chat history beyond song titles/errors |

Nothing is uploaded to a server operated by this project. There is no telemetry.

## Windows-only helpers

`tools/lift-cookie.mjs` (with `qq-lift-cookie.ps1` / `QqMemScan.cs`) reads the
memory of a **running QQ Music for Windows client on the same machine** to lift
its own login cookie. That is the same data the client already holds; the tool
does not modify the client and does not bypass any access control. Only run it on
a machine and account you own.

## Reporting a vulnerability

Open a private security advisory on GitHub (Security → Report a vulnerability)
or email the maintainer. Please do not file public issues for anything that could
leak a cookie or execute code.

## Scope / disclaimer

- QQ Music endpoints used here are unofficial web endpoints. They are not a
  stable or licensed API; use them for personal use on your own account only.
- Voice models (RVC `.pth`/`.index`) are third-party assets with their own
  licenses. Train/obtain them responsibly; do not use someone else's voice to
  impersonate or defraud.
- Covers generated by this plugin are for personal entertainment. Do not publish
  or monetize them without the rights holders' permission.
