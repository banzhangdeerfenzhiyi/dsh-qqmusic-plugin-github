# 微信 4.1.10.27 客户端说明

## 为什么这里没有微信客户端安装包

- 微信（Weixin）客户端是腾讯公司的专有软件，**不允许再分发**，本仓库不提供腾讯微信安装包。
- 本机也没有保存 4.1.10.27 的官方安装器文件；只有已安装好的客户端目录。
- 好消息：**上游 WeChatAgent 安装包（`installers/WeChatAgent-Setup-0.4.1-x64.exe`）已内置
  维护者已授权的匹配微信 4.1.10.27 客户端与原生发送组件**。按 `教程.md` 正常安装即可，
  一般不需要单独准备客户端安装包。

## 如果你确实需要单独准备客户端

例如从旧机器迁移，或重新安装后要恢复匹配客户端，按下面步骤校验：

1. 从**你有权使用的来源**获取 4.1.10.27 的客户端程序文件（不是本仓库提供的）。
2. 校验版本与签名：

```powershell
$exe = 'D:\WeChatAgent\data\workspace\state\hook\wechat-4.1.10.27\Weixin.exe'
(Get-Item $exe).VersionInfo.FileVersion          # 必须是 4.1.10.27
Get-AuthenticodeSignature $exe | Format-List Status, SignerCertificate
# Status 应为 Valid，签名者证书主题应包含 Tencent
```

3. 目录结构应与项目期望一致（安装器生成的样子）：

```
<安装根目录>\data\workspace\state\hook\wechat-4.1.10.27\
├── Weixin.exe                  # 启动器（版本 4.1.10.27）
├── version.dll                 # 本项目部署的 Hook DLL（由 prepare/launch 写入）
├── wechatagent-hook.token      # 本地令牌（由 prepare/launch 写入）
└── 4.1.10.27\                  # 客户端程序文件（Weixin.dll 等）
```

4. 客户端位置在 `data\workspace\config\wechatagent.json` 的
   `hook.wechatExecutable` 指定（默认 `state/hook/wechat-4.1.10.27/Weixin.exe`）。
5. 部署与校验统一走 `wechat-deploy-plugin` 的 `wechat_deploy_status`：
   它会检查 FileVersion、`version.dll` 与 `state/hook/native/build.json` 的 SHA256 是否一致、
   Hook 健康状态与进程归属。也可以用命令行：

```powershell
cd <DSH_HOME>\dsh-wechat-deploy-plugin
node tools/status-cli.mjs
```

## 重要提醒

- **不要升级**匹配客户端：项目锁定 4.1.10.27，并通过客户端目录 ACL 写保护 + 禁用更新器
  降低版本漂移；升级后 Hook 需要重新适配与验证。
- 校验用的版本号不能只改配置：`launch-hook-wechat.ps1` 还会校验客户端签名（Tencent）
  与 `version.dll` 哈希，不匹配会拒绝启动。
- 本仓库不提供微信客户端、`version.dll` 构建产物或任何腾讯程序文件。
