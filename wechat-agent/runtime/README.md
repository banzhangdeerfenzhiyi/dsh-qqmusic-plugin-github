# WeChatAgent 0.4.0

Windows 微信助手与桌面控制台。为允许的好友和群聊提供人格聊天、独立上下文、按需联网搜索、图片与表情理解、原生表情发送，也可将微信作为 DSH 的远程任务入口。

## 0.4.0 更新

- 完善助手模式：按聊天授权 DSH 能力、管理员控制、任务管理、原生审批和普通文件收发。
- 新增可编辑的任务语录，减少排队信息、任务编号及后台命令完成通知对刷屏的影响。
- 主导航整理为 **概览、聊天、人格、能力、表情包、设置**，合并重复入口，明确账号默认与单聊覆盖。
- 保留已有账号、人格、授权、工作区及会话历史；完整变更见[发布说明](RELEASE_NOTES.md)。

## 安装与升级

安装包文件名为 WeChatAgent-Setup-0.4.0-x64.exe，适用于 Windows 10/11 x64，由维护者上传至 GitHub Releases。源码目录不包含安装器和第三方二进制。

1. 选择一次安装根目录：程序放入 app，WeChatAgent 配置、缓存和运行数据放入同级 data。
2. 在首次配置中打开匹配微信并登录，自动查找账号，再连接并验证数据库。
3. 从 [DSH 官方页面](https://www.deepseek.com/harness/)单独安装 DSH，登录模型账号，选择程序位置并启用本项目插件。可复制插件目录，误删后重新添加。
4. 在“聊天”添加允许的好友或群聊，保存设置并启动服务。初始允许范围为空。

同位置升级沿用已有数据位置；更换位置时核对迁移来源和目标，原副本保留。升级前停止助手服务并完整退出旧版助手、DSH 和匹配微信；升级后准备连接配置，完整重开 DSH 加载新版插件。详见[安装发行版](docs/INSTALLER_RELEASE.md)、[数据位置与迁移](docs/DATA_STORAGE.md)。

DSH 桌面程序不内置，数据由其独立管理；微信原始数据库不随助手数据目录搬动。窗口“×”继续收起到托盘，“退出应用”会先停止本实例后台服务，微信和外部 DSH 保持运行。

## 界面与功能位置

| 页面 | 主要内容 |
| --- | --- |
| 概览 | 服务开关、微信和 DSH 状态、最近记录、诊断入口 |
| 聊天 | 允许范围、好友/群筛选、工作区分组；选中后查看概况、任务与文件、历史与用量 |

## 聊天模式与助手模式

**聊天模式**用于人格聊天，支持群聊自然参与或唤醒后回复、图片与表情理解、搜索、主动聊天及上下文管理。普通群消息也可能触发模型判断，选择沉默仍可能产生模型消耗。

**助手模式**用于从微信交办任务。DSH 工具、技能和插件在 DSH 安装与管理，WeChatAgent 按聊天分配能力；可逐项授权，或显式选择使用所选 DSH 预设的可用能力。实际操作继续遵守原生权限与审批，纯界面插件不会成为可执行工具。

1. 在“设置 → 助手设置”添加真实管理员微信 ID 并保存。
2. 在目标聊天的基本设置中选择助手模式。
3. 在“能力与权限”选择任务预设与授权范围；按需要启用文件收发、联网搜索及微信审批。
4. 在微信描述任务，或发送“助手帮助”“助手能力”“任务列表”“任务状态”“取消任务”。群聊仍需按本群规则唤醒。

私聊助手仅供指定管理员使用。群管理员模式可独立开关；关闭后成员可使用本群已授权能力，仅管理自己的任务。群内共用工作区和历史，并非每位成员独立的系统沙箱。原生审批默认在电脑端，微信确认需明确启用并核对一次性操作。

两种模式分别保留设置与上下文。DSH 重启时进行中的任务标记中断，核对结果后再继续，不自动重跑可能已经发生的操作。详见[远程助手](docs/ASSISTANT_REMOTE.md)、[按聊天授权](docs/DSH_CHAT_ACCESS.md)。

## 文件与任务反馈

助手可接收微信普通附件，并回传当前 DSH 工作区成果，单个文件最多 50 MB。电脑微信需已下载完整文件；收到附件不代表已经解析正文。PDF、Office 等需要所选 DSH 技能、工具及相应依赖。文件内容不会自动执行。详见[文件收发](docs/FILE_TRANSFER.md)。

任务语录在“设置 → 助手设置 → 管理语录”中按七个阶段增删改，可选择关闭、普通或整活档位。默认每 15 秒最多反馈一次、每任务最多 3 条常规反馈；语录由本地程序选择，不额外调用模型，不写入任务提示词或人格。整活档位隐藏排队、任务编号和工具明细，后台命令成功通知静默处理；审批、提问、失败和定时任务结果仍保留。详见[自定义语录](docs/ASSISTANT_FEEDBACK.md)。

## 联网、表情与记忆

| 功能 | 使用位置与条件 |
| --- | --- |
| 联网搜索与天气 | 能力 → 联网与阅读。按对话调用 DSH 网页搜索，无需给出网址；支持单聊覆盖、每轮次数、缓存及超时设置 |
| 网页阅读 | 同一页面独立控制，读取公开网页实际正文；不代表观看视频或访问需登录的内容 |
| 手动添加表情 | 表情包 → 我的表情，添加、预览、编辑描述与标签或删除 |
| 收集与共享 | 表情包 → 自动收集，同一账号已允许聊天共享最多 50 张；满池后 DS 按预览、标签和使用情况选择保留 |
| dsh-meme 图库 | 先在 DSH 安装并启用原插件，再到表情包 → 来源与搜索配置接入和聊天范围；可按需要开启联网补图 |
| 表情发送 | 表情包 → 发送设置；单聊可覆盖。资源缺失时可在来源设置中配置腾讯下载与兼容选项 |
| 群友记忆 | 能力目录中管理，按稳定成员 ID 保存有限标签，同一账号内按群隔离，模型需要时读取 |
| 主动聊天 | 设置 → 聊天默认值打开总开关，并逐个聊天加入；不用于助手模式主动执行任务 |
| 上下文压缩 | 设置 → 上下文；单聊留空继承、0 关闭，历史与用量页保留手动压缩入口 |

dsh-meme 需用户自行安装，本项目适配其现有接口，不修改原插件。联网补图还需对应聊天开启搜索与表情发送；选图、识图与满池评选可能产生模型消耗。动图保留发送动画，理解使用有限帧采样，不保证完整理解每一帧。详见 [dsh-meme 接入](docs/DSH_MEME.md)、[表情管理](docs/STICKER_MANAGER.md)、[群友记忆](docs/MEMBER_MEMORY.md)。

## 连接、更新与限制

匹配微信为 Windows x64 **4.1.10.27**；桥接插件 SDK 为 **0.2.0-rc.2**，DSH 需支持项目插件和原生会话接口。程序不会提供通用新版微信适配，也不自动修改系统 DNS 或代理设置。

连接和账号设置在“设置 → 微信与 DSH”；读取/发送检查、连接修复、端口进程排查和准备配置集中在“诊断”。停止进程仍需核对并二次确认；原始日志保留筛选和脱敏导出。

启动时检查 GitHub Releases，也可点击侧栏“检查更新”。发现新版或同版本新构建时提示下载，不自动安装；网络失败不阻断聊天。安装包、源码、SHA256SUMS.txt 和 VERIFICATION.json 的实际版本与验证范围以对应 Release 为准。

## 源码与构建

源码不含账号、凭据、联系人、聊天记录、微信客户端或原生 DLL。公开预设为维护者已授权的通用人格。开发构建需准备已授权的匹配微信、Hook 编译产物、wx_key.dll 和读取依赖；普通安装版用户无需安装开发工具。

在 Windows 环境安装根目录和 DSH 插件的锁定依赖，然后构建；**无需提供 DSH 桌面程序或设置 WECHATAGENT_DSH_SOURCE**。

```powershell
npm ci
npm ci --prefix packages/dsh-social-bridge-plugin
npm test
npm run privacy:check
npm run desktop:build
npm run installer:runtime
npm run installer:build
```

安装器输出到 release/installer，构建按根 package.json 版本命名。可复用已校验的 Python 构建缓存；第三方组件遵守各自许可，参见 [LICENSES.md](LICENSES.md)。发布验证使用隔离目录和虚构账号；不以自动化测试替代另一台物理设备的真实账号验收。
