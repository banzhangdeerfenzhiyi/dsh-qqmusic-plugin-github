# DSH 插件拒绝请求排查

`DSH plugin: agent_unavailable (LOCAL_PERSONA_CONFIG_REQUIRED)` 表示本机生成的人格配置缺失或无效。插件只使用本机 `state/bridge-config.json` 中的配置，聊天消息不能替换它。

人格编辑、导入、启动准备和插件统一支持最多 60,000 字节的 UTF-8 人格内容。启动准备会校验已绑定卡片，空内容、超限或只包含其他模式内容的卡片会在本机直接提示修正，不再等到消息投递时才报泛化错误。

修正人格后，在“工具”中准备配置，再完整重开 DSH 和助手服务。保留旧会话和消息数据，不需要归档或删除聊天。若另一台设备仍使用旧安装包，需要更新对应代码或安装新版；本机正常不会自动修复远程设备。

`request_too_large` 表示内部 RPC 传输包过大，与模型上下文容量不同。新版每轮使用人格 SHA-256 摘要核对本机配置，不再重复发送整张人格卡；内部传输按 UTF-8 字节计数，设有 256 KiB 上限。原有单轮聊天文本上限保持 18,000 字符。

超过传输上限会在模型接收前返回 HTTP 413 和 `REQUEST_TOO_LARGE`，附带 `admitted:false`。请求不会进入模型或污染会话，后续合规请求仍可处理。程序不会为了通过限制而截断人格、绕过本机配置校验或重复提交已进入模型的批次。
