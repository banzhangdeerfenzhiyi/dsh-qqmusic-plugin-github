# 助手模式

完整设置、微信命令、原生预设、任务恢复和审批说明见 [微信远程助手](ASSISTANT_REMOTE.md)。

## 管理员控制

在“回复设置 → 助手模式管理员”中从微信好友选择管理员，也可每行填写一个真实微信 ID（wxid），再保存设置。名单按当前微信账号保存，切换账号不会沿用另一账号的名单；昵称或聊天中的身份声明无效。

在“聊天范围 → 群聊 → 会话设置”切换至**助手模式**后，可开关该群的**管理员模式**，默认开启。开启时仅名单中的管理员可发起、查询或取消任务；关闭时群成员可使用本群已勾选的能力，非管理员只能查询或取消自己发起的当前任务，管理员可管理当前任务。私聊助手始终仅允许管理员。名单为空时，私聊及开启管理员模式的群不会执行助手任务。

不同发送者的请求分批串行处理；群内仍共用该群的 DSH 会话与工作区，任务结果在群内可见，不是每位群友的私密工作区。新增任务、恢复队列、重试投递和工具执行都会检查权限。收紧权限后尚未执行的请求会丢弃，已经执行的操作不会撤回。开关和名单只能在本机界面修改，原生权限审批默认在本机完成，也可在本聊天开启管理员微信审批。

## 微信文件与联网搜索

在当前会话的助手模式设置中开启“微信文件收发”，默认关闭。私聊仍仅管理员可用；群聊沿用该群管理员开关。发送给机器人的文件会成为本轮文件引用，助手可用 `wechat_file_receive` 将它复制到当前 DSH 工作区，再使用本群已授权的读取工具处理。单文件最多 50 MB，保留普通文件格式，不把文件名或路径当作已读内容。

电脑微信需要已下载完整文件。未下载、同名无法确认或校验失败时立即说明，稍后下载后可重新发送文件；读取失败不会卡住后续文字。接收文件位于工作区的 `.wechatagent-files/incoming/`，按账号、聊天、发起者与消息编号分目录；同一群本身仍共享工作区和历史。

让助手回传成果时，它会调用 `wechat_file_send`，只接受当前工作区中的相对路径。后台发送队列独立于文字回复；排队、微信提交与服务器确认分别记录，网络结果不确定时不重复发送。可用 `wechat_file_status` 查询状态。传输状态与发送缓存位于程序数据目录 `workspace/state/files/`，当前累计上限 512 MB / 128 个传输记录；达到上限需在本机核对并整理缓存。

需部署本次编译的新 Hook 后重启匹配微信，才能启用原生文件发送；旧组件会明确显示未就绪，不降级为路径、网页链接或表情。当前尚未将所有 DSH 界面功能映射到远程任务管理。

在当前会话开启“联网搜索”即可使用 DSH 原生搜索，无需额外搜索 API 密钥。工具名为 `wechat_web_search`，内部调用 DSH 的 `web.search` 服务，并保留会话开关、每轮次数、超时及来源校验。独立工具名避免与第三方插件的 `web_search` 重名注册；DSH 的登录及原生搜索服务需可用。


在「聊天范围 → 会话设置 → 工作模式」选择「助手模式」并保存。已有聊天保持「聊天模式」。每个好友和群可分别选择，聊天历史、人格选择、技能及工具授权、功能覆盖设置按模式保留，切回后继续对应历史。

保存助手模式并连接 DSH 后，打开该聊天的「技能与工具」，刷新并勾选需要的能力。初始工具授权为空。也可在“技能与工具”选择已有 DSH 任务预设和“使用 DSH 可用能力”，保留原生权限与审批。文件读写、终端、文件搜索、后台任务工具来自 DSH；搜索、网页阅读和表情包沿用现有开关与插件。自定义 DSH 插件仍在 DSH 安装和管理。助手默认使用 `wechat-assistant` 预设，也可在本聊天选择已有 DSH 预设；不会修改 `standard` 或原有聊天预设的定义。

群聊默认唤醒后执行，也可在该群单独选择自然参与。助手管理员指本机指定的微信账号，与微信群自带的群主或管理员身份无关。原生权限审批默认在 DSH 本机完成，也可在本聊天开启管理员微信逐次确认；不改变 DSH 自身审批策略。联网搜索开关管理搜索和网页能力，不是终端命令的网络沙箱；终端权限继续由 DSH 管理。

在「会话」页面查看或取消当前任务。微信私聊发送「任务状态」或「取消任务」也可操作；群聊需要 @ 或唤醒助手。控制消息可以在模型和工具执行期间处理，不排在当前任务之后。任务默认最多执行 30 分钟，可在本聊天调整为 5–120 分钟，达到时限请求取消；工具是否能立即结束由 DSH 及相应插件决定。

助手回复保留列表和代码，不应用闲聊的两条短消息拆分；单次回传最多 12,000 字符。微信入口支持任务编号、状态、取消、续接、工作区选择、原生提问及可选管理员审批。通过助手建立且发起者绑定明确的原生定时任务及后台任务可独立通知微信；界面插件不会自动变成工具。

正在执行或已有待投递回复时，先完成/取消当前任务，再切换模式。普通关闭窗口仍收起到托盘，退出应用沿用原服务停止机制。

插件名称、来源分组及已有授权的处理见[插件目录说明](PLUGIN_CATALOG.md)。
