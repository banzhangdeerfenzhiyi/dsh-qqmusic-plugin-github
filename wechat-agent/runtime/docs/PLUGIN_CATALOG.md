# DSH 插件名称与工具授权

「聊天范围 → 会话设置 → 技能与工具」按来源展示模型可调用的能力。

- **技能**：使用 DSH 技能清单中的名称。
- **DSH 内置能力**：当前预设加载的文件、终端、文件搜索、后台任务等工具。
- **插件分组**：标题使用 DSH 插件管理器提供的名称，下面保留包名、版本和各个工具 ID。相同标题但不同包的插件不会合并。
- **来源未确认的工具**：缺少注册来源或归属不唯一时单列，不根据工具名前缀猜插件。
- **已分配但未加载的工具**：保留原有勾选，可以取消授权；恢复插件后刷新清单。
- **其他已安装的 DSH 插件**：折叠展示当前没有已确认可授权工具的插件。界面插件只在 DSH 中使用。dsh-meme 的微信表情库接入仍在 WeChatAgent 扩展页面配置。

名称、分组和搜索是展示信息。授权仍按每个会话原有工具 ID 保存，不会因为插件改名、分组变化或同名插件而增加权限。没有“启用整个插件就自动授权全部工具”的行为。

工具归属来自实际注册上下文，通过 Cordis 的服务访问器记录，不修改 DSH 安装文件或第三方插件。助手预设等待来源目录就绪后再组合工具。先于目录加载且没有可靠来源的工具会保持“来源未确认”；它们原有授权和执行逻辑不变。

更新后需要完整重开 DSH 与 WeChatAgent，加载新版插件目录和前端。旧版 DSH 不支持目录元数据时会保留工具和已有授权，并提示来源信息不可用。
