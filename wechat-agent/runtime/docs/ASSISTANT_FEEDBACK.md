# 助手任务反馈与自定义语录

当前界面位置见[导航与设置说明](UI_LAYOUT.md)，旧链接仍可跳转到对应页面。

进入 **设置 → 助手设置 → 助手任务反馈 → 管理语录**。这套设置独立保存，无需重启 DSH 或微信服务，保存后用于后续反馈。它只作用于助手模式，普通聊天不自动插入进度语录。

## 添加与修改

选择“任务阶段”，在“本阶段语录”中每行写一句。可以直接修改已有文字、另起一行添加，或删除整行。每个阶段最多 30 条，每条最多 160 字；重复内容会合并。整活档位清空某个阶段的语录后，只显示简短的阶段名称；失败时仍保留具体错误。

“添加语录”会将光标放到新行；“恢复本阶段默认语录”只重置当前阶段的草稿，最后点击“保存语录”才会生效。切换阶段会保留其他阶段尚未保存的修改，关闭窗口时会提示未保存内容。并发编辑发生冲突时不会覆盖另一个窗口已经保存的版本。

阶段包括：接到任务、读取文件、查找资料、执行工具、继续处理、处理完成、任务失败。阶段由实际任务状态和当前工具决定，不根据语录倒推任务是否已经执行。

## 档位与频率

- **关闭进度播报**：不发送常规进度与语录，必要的审批、提问仍会完整提醒。
- **普通**：显示真实任务编号、阶段与工具信息。
- **整活**：从当前阶段的语录中选一句，只发送语录，不附带任务编号、“排队中”或工具明细。默认使用此档位。审批、提问与失败信息保留必要详情。

默认间隔 15 秒，每个任务最多 3 条常规反馈；可调整为 15–120 秒、1–5 条。短任务只反馈接单，随后直接发送模型结果，避免额外完成播报。较长任务可在上限内发送完成或失败反馈；最终结果、审批和提问不占用语录条数。

语录尽量避开近期已使用的句子。同一条反馈使用稳定的投递编号，重试和重启会继续核对原消息，不换一句重新发送。语录发送失败不影响任务继续执行或正常返回结果。

后台工具命令成功结束时，不再单独发送“后台任务 pwsh-… 已结束，状态：completed”这类系统通知；旧版本积压的同类成功通知也会静默处理。任务正文、定时任务结果和失败提醒仍会发送。

## 语录与任务分离

语录由本地程序选择，不额外调用模型，也不会写入任务提示词、角色卡或用于接话的消息缓存。它们是进度文案，不是模型真实的内部思考。比如“要不随便糊弄一下用户……算了，鱼也是有职业道德的”只是一条显示给用户的语录，不会变成助手的工作规则。

审批动作、一次性编号、提问内容和真实错误仍按原流程显示。发送“任务状态”或“任务列表”仍可主动查看完整任务信息。编辑语录不会改变管理员名单、工具权限或审批结果。

用户语录保存在程序数据目录的 `workspace/config/assistant-feedback.json`，首次保存时创建；已有配置会保留一份 `.bak`。投递与近期去重状态位于 `workspace/state/assistant-feedback/<账号标识>/state.json`，按微信账号隔离，最多保留 256 个任务状态。
