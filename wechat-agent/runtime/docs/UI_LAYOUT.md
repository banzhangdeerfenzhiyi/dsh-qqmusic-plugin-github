# 界面导航与设置位置

主导航整理为六项。已有账号、人格、聊天/助手模式历史、工作区、工具授权及配置字段继续沿用。

| 页面 | 内容 |
| --- | --- |
| 概览 | 服务开关、微信/DSH连接状态、最近活动、诊断入口 |
| 聊天 | 允许的好友和群聊、搜索和模式筛选、工作区分组；选中后查看概况、任务与文件、历史与用量 |
| 人格 | 人格卡导入、新建、分类、编辑和删除，以及使用该卡的聊天 |
| 能力 | 内置能力与来源、联网搜索与网页阅读、DSH技能与工具概览 |
| 表情包 | 我的表情、自动收集、来源与搜索、发送设置 |
| 设置 | 聊天默认值、助手设置、上下文、微信与DSH、诊断、日志、开发者选项、外观与数据 |

## 设置一个聊天

进入“聊天”，选择好友或群聊，再点击“设置此聊天”。

- **基本设置**：工作模式、人格和群聊回复方式；聊天模式还可选择主动聊天。
- **能力与权限**：表情和搜索覆盖、DSH工具/技能授权、助手预设、文件收发、管理员模式和审批方式。
- **高级**：此聊天的上下文阈值；助手模式另有任务时限、工具调用上限。

保存仅提交这个聊天，其他页面的草稿会保留。聊天和助手模式各自保存设置及上下文，切回可继续使用原历史。选择“使用 DSH 可用能力”时，原先逐项授权的列表仍保留；实际操作继续经过原生权限和审批。

“任务与文件”显示助手任务列表和文件收发状态，可查看具体任务或取消尚未结束的任务。不会因打开页面而提交新任务、发送文件或取消任务。普通文件成果仍位于对应DSH工作区，不增加新的文件管理后端。

“历史与用量”集中显示上下文、压缩与token统计，session ID等内容收进技术信息。工作区分组仍同步DSH；跨目录移动继续使用已有确认和保留历史流程。

## 全局默认与单聊覆盖

界面显示“继承账号默认”“本聊天单独设置”或“总开关关闭”。这些文字反映现有配置规则：

- 联网搜索、表情发送使用账号默认值，单聊可以覆盖。
- 主动聊天需要总开关开启，且该聊天明确加入；助手模式不主动执行此类聊天任务。
- 上下文压缩需要总开关开启；单聊留空继承阈值，0关闭。
- 网页阅读当前为全局能力，没有新增单聊授权开关。

## 常用功能位置

| 功能 | 位置 |
| --- | --- |
| 群聊参与、唤醒词、昵称、回复节奏、主动聊天时间 | 设置 → 聊天默认值 |
| 管理员名单、任务反馈、自定义语录 | 设置 → 助手设置 |
| 默认压缩阈值和空闲时间 | 设置 → 上下文 |
| 搜索开关、摘要缓存、次数和超时 | 能力 → 联网与阅读；具体参数可展开 |
| 网页阅读 | 能力 → 联网与阅读 |
| 群友记忆 | 能力 → 能力目录 → 群友记忆 |
| dsh-meme接入、聊天范围、联网补图 | 表情包 → 来源与搜索 → 配置图库接入与聊天范围 |
| 收集、共享、标签复用、满池评选状态 | 表情包 → 自动收集 |
| 原生表情发送默认值 | 表情包 → 发送设置 |
| 腾讯缺失资源下载和旧域名兼容 | 表情包 → 来源与搜索 → 缺失资源下载与旧版兼容 |
| 微信账号连接、模型和程序位置、复制插件路径 | 设置 → 微信与DSH |
| 检查读取/发送、准备配置、重开DSH确认、修复连接、端口与进程 | 设置 → 诊断 |
| 原始日志筛选和导出 | 设置 → 运行日志 |
| 构建/验证组件、依赖安装、客户端写保护 | 设置 → 开发者选项 |
| 主题、桌面背景、当前工作区数据位置 | 设置 → 外观与数据 |

首次配置完成后不再常驻导航，可在“设置 → 微信与DSH”重新打开向导。DSH仍独立安装，插件和技能仍在DSH管理；WeChatAgent展示来源和分配入口。

## 保存与生效

账号默认值沿用底部“保存设置”；人格卡、单聊弹窗和语录库各自独立保存，并保留未保存修改提示。页面重排不会自动扩大权限或改变功能开关。

支持热更新的开关保存后作用于后续消息；人格、模型或端口等变更继续按原规则提示重启服务或完整重开DSH。诊断、修复和停止进程保留原有确认流程。

旧链接继续兼容：`#sessions`进入聊天的历史与用量，`#behavior`进入聊天默认值，`#connections`进入微信与DSH，`#tools`进入诊断，`#logs`进入运行日志。页面分别记录滚动位置，首次进入从页首开始。
