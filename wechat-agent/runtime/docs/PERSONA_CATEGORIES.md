# 人格分类

打开“人格”，点击“新建分类”，例如“日常聊天”“创作角色”。分类建立后，打开已有的人格卡，点击“移动分类”选择目标。可随时移回“未分类”。

- 页面上方可切换“全部”“未分类”和自定义分类，数字表示卡片数量。
- 在“管理分类”中重命名或删除分类。删除分类时，卡片会保留并移入“未分类”。
- 新建、导入的人格默认未分类；替换同名人格保留原分类。
- 切换分类和移动卡片保留编辑草稿。分类单独立即保存，无需重启机器人或 DSH。
- 分类仅用于整理人格卡，不会修改卡片文件名、内容、默认人格、聊天绑定或会话工作区。

分类信息保存在当前数据目录的 `workspace/state/persona-categories.json`（开发版为项目内 `state/persona-categories.json`），随 WeChatAgent 数据迁移保留。旧版卡片首次使用时自动显示在“未分类”，不需要搬动 Markdown 文件。

多窗口同时修改时，旧窗口会提示刷新，避免覆盖已保存的分类。若分类文件损坏，原文件保留；人格卡仍可读取和编辑，分类管理会显示错误提示。
